# Raw data

Download the source dataset from Kaggle:

**[Spotify Music Analytics Dataset (2015–2025)](https://www.kaggle.com/datasets/rohiteng/spotify-music-analytics-dataset-20152025)**  
Author: [rohiteng](https://www.kaggle.com/rohiteng)

## Place file here

**Expected file name:** `spotify_2015_2025_85k.csv`  
(Configured in `configs/pipeline_config.yaml`)

**Full path:**

```text
data/raw/spotify_2015_2025_85k.csv
```

Raw CSV files are not committed to git (see root `.gitignore`). Add the dataset locally after cloning the repository.
